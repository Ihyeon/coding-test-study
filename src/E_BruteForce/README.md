# Brute Force (브루트포스 / 완전 탐색)

## 1. 개념
- **"Brute" (무식한) + "Force" (힘)**
- 가능한 **모든 경우의 수**를 전부 시도하여 정답을 찾는 가장 직관적인 알고리즘
- 특별한 기법(DP, 그리디 등)을 쓰지 않고, 컴퓨터의 빠른 계산 능력을 이용해 1부터 100까지 다 대입해보는 방식

## 2. 특징
- **장점**
    - 알고리즘 중 가장 직관적이고 구현이 쉬움
    - 답이 존재한다면 **반드시 찾을 수 있음** (완전성 보장).
- **단점**
    - 입력 크기(N)가 커질수록 실행 시간이 기하급수적으로 늘어남
    - 실행 시간 제한이 타이트한 문제에서는 시간 초과가 날 수 있음

## 3. 시간 복잡도
- 보통 **$O(N^2)$** 이상이거나 지수 시간($O(2^N)$, $O(N!)$)
- **사용 시점**
    - 입력 크기($N$)가 매우 작을 때 (예: $N \le 100$ 또는 $N \le 20$ 등 문제에 따라 다름)
    - 다른 효율적인 알고리즘이 떠오르지 않을 때 최후의 수단으로 사용

## 4. 구현 방식
1. **반복문 (For / While):** 단순하게 $i, j, k...$ 등 변수를 늘려가며 다중 반복문 사용
2. **재귀 (Recursion):** 백트래킹(Backtracking)과 결합하여 깊이 우선 탐색(DFS) 형태로 구현
